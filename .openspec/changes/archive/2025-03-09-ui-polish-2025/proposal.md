# UI Polish 2025 - Proposal

## Overview

系统性地优化 ChronoFlow 的用户界面，提升视觉一致性、交互体验和核心功能的易用性。

## Problem Statement

当前界面存在以下问题：

1. **布局问题**：导航栏和任务清单栏采用不同的交互模式（固定侧边栏 vs 可折叠），缺乏一致性
2. **视觉问题**：
   - 计时器数字在页面过窄显示时会溢出卡片边界
   - 任务清单栏内部多层边框造成视觉混乱
   - 标签（Chips）尺寸过小，不够醒目
3. **交互问题**：
   - 缺少全局快捷键支持
   - 没有全局计时状态指示器，切换标签页后无法看到当前计时状态
4. **项目视图问题**：
   - 任务卡片信息密度过高
   - 简介描述占用空间但价值不高
   - 任务名称过长时显示不完整

## Goals

1. **统一交互模式**：导航栏和任务清单栏均采用抽屉式设计
2. **修复视觉问题**：解决计时数字溢出，优化标签显示
3. **增强核心功能**：添加空格键快捷键和全局计时状态指示器
4. **优化项目视图**：改进任务卡片的信息展示

## Scope

### Included

- 导航栏改造为抽屉式
- 任务清单栏改造为抽屉式
- 计时器数字显示修复
- 空格键快捷键（计时控制）
- 全局计时状态指示器
- 项目任务卡片优化
- ESC 键关闭抽屉
- 无障碍支持（焦点管理、ARIA 标签）

### Excluded

- AI 功能重设计（计划替换为日历功能，后续迭代）
- 深色模式优化
- 移动手势支持（后续迭代）
- 状态持久化（抽屉状态不保存）

## Success Criteria

1. 用户可以通过一样的汉堡菜单操作导航栏和任务清单栏
2. 计时器数字在任何时长下都不会溢出卡片
3. 用户可以通过空格键快速控制计时开始/暂停
4. 用户可以在任何标签页看到当前计时状态
5. 项目任务卡片更清晰地展示关键信息
6. 所有交互都支持键盘操作和屏幕阅读器

## Dependencies

- 无外部依赖
- HeroUI 组件库已集成（用于 Tooltip）

## Risks

| Risk | Mitigation |
|------|------------|
| 抽屉式布局可能减少屏幕利用率 | 响应式宽度设计，移动端/桌面端自适应 |
| 空格键快捷键可能干扰输入 | 仅在有活动计时器时生效，在输入框中禁用 |
| 全局指示器可能遮挡内容 | 使用固定高度、可最小化设计 |

- 计时器修复：30 分钟
- 快捷键实现：1 小时
- 全局指示器：1 小时
- 项目卡片优化：1 小时
- 测试和调整：1 小时
