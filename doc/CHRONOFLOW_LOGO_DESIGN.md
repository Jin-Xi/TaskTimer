# ChronoFlow Logo 设计方案

> 自然流动的生产力工具品牌标识

---

## 设计理念

ChronoFlow 的 logo 设计围绕**"自然流动"**这一核心理念展开，结合时间管理、任务流转、AI 辅助三大核心功能，打造既现代又富有温度的品牌形象。

### 关键设计元素

| 元素 | 含义 | 视觉呈现 |
|------|------|----------|
| **时间** | 计时、番茄钟 | 沙漏、圆环、进度条 |
| **流动** | 任务流转、工作流 | 波浪、曲线、渐变 |
| **生长** | 进度推进、任务完成 | 植物、分支、向上箭头 |
| **智能** | AI 辅助分析 | 核心光点、神经网络暗示 |

---

## 品牌配色

| 色系 | 颜色名 | Hex | 应用 |
|------|--------|-----|------|
| **品牌主色** | Primary Green | `#84B179` | 主体轮廓、品牌识别 |
| **进行中** | Ochre | `#E5A952` | 活跃状态、流动元素 |
| **终止/警告** | Terracotta | `#D27D67` | 终止节点、状态标识 |
| **AI 智能色** | Slate River | `#6B8E9B` | AI 核心、智能暗示 |

## Logo 方案

### 方案 A：流动沙漏 (Flowing Hourglass)

**适合场景：** 大型展示、引导页、功能介绍

```
┌─────────────────────────┐
│                         │
│         ╱   ╲           │  ← 绿色轮廓 (#84B179)
│        ╱  ~  ╲          │
│       ╱   ~~   ╲         │  ← 流动沙粒渐变
│      ╱ ~~~~~~~~ ╲        │     (#84B179 → #E5A952)
│     ╱~~~~~~~~~~~~╲       │
│    ╱──────●──────╲      │  ← 焦点圆点 (#6B8E9B)
│   ╱               ╲      │
│  ───────────────────     │
│                         │
└─────────────────────────┘
```

**视觉特点：**
- 上半部分实心绿（待完成任务）
- 下半部分赭土黄（进行中状态）
- 中间连接处蓝色焦点（AI 核心）
- 沙粒以波浪形态呈现，增强流动感

---

### 方案 B：分支藤蔓 (Branching Vine)

**适合场景：** 项目管理模块、工作流展示

```
                    │
                ┌───┴───┐
             ┌──┘       └──┐
          ┌──┘             └──┐
       ┌──┘     ◉            └─●     ← ◉ 终止节点
     ─┴─        ↑              ●      ← ● 完成节点
    主干       ↑             分支
 (绿色渐变)   AI 核心       (赭土黄)
```

**视觉特点：**
- 主干向上生长（绿色渐变）
- 分支向两侧展开（赭土黄）
- 叶子代表任务节点
- 终止节点用陶土红圆点

---

### 方案 C：字母 CF 极简几何

**适合场景：** Favicon、小图标、移动端

```
┌─────────────────┐
│                 │
│    ╭──────╮     │  ← C 形 (绿色 #84B179)
│    │      │     │
│    │ ████ │     │  ← 进度条 (赭土黄 #E5A952)
│    │      │     │     填充约 60%
│    ╰────╯─│     │
│            │     │
└─────────────────┘
```

**视觉特点：**
- C 形：270° 不完整圆环（时间循环）
- F 形：横杠是进度条（任务进度）
- 共用竖线，结构稳固
- 极简设计，小尺寸清晰

---

### 方案 D：同心圆渐变

**适合场景：** 品牌宣传、深色模式

```
         ╱─────╲
       ╱   ╱   ╲
     ╱   ╱   ●   ╲    ← 最内圆：Slate River (#6B8E9B)
    │   ╱         │       第二圆环：Green (#84B179)
     │ ╱         │       第三圆环：Ochre (#E5A952)
      ╲         ╱         最外圆环：Light Green (#C7EABB)
       ╲─────╱
```

**视觉特点：**
- 3-4 个同心圆，从内到外变淡
- 内圆是 AI 核心（蓝色）
- 外圆环呈渐变循环
- 圆环粗细递减

## 推荐应用策略

| 场景 | 推荐方案 | 原因 |
|------|----------|------|
| **Favicon** | 方案 C (字母 CF) | 16px 下仍可识别 |
| **PWA 图标** | 方案 A (流动沙漏) | 表达核心功能 |
| **页头 Logo** | 方案 A + 文字 | 品牌展示 |
| **项目管理模块** | 方案 B (分支藤蔓) | 呼应工作流概念 |
| **深色模式** | 方案 D (同心圆) | 视觉柔和 |

## 文件规格

### SVG 文件（矢量）
| 文件名 | 尺寸 | 说明 |
|--------|------|------|
| `logo-full.svg` | 200x60 | 带文字的水平版 |
| `logo-icon.svg` | 64x64 | 纯图标版 |
| `logo-horizontal.svg` | 180x50 | 图标 + 文字（紧凑） |

### Favicon（位图）
| 文件名 | 尺寸 | 格式 |
|--------|------|------|
| `favicon-16x16.png` | 16x16 | PNG |
| `favicon-32x32.png` | 32x32 | PNG |
| `favicon-48x48.png` | 48x48 | PNG |
| `favicon.ico` | 多尺寸 | ICO |

### PWA 图标
| 文件名 | 尺寸 | 说明 |
|--------|------|------|
| `icon-192.png` | 192x192 | Android 平板 |
| `icon-512.png` | 512x512 | iOS/高分辨率 |

## 使用指南

### 在 React 组件中使用

```tsx
import { Logo } from '@/components/Logo';

// 页头使用
<Logo variant="full" size={120} />

// 导航栏使用
<Logo variant="horizontal" size={32} />

// 图标按钮
<Logo variant="icon" size={24} />
```

### 颜色自适应

Logo 组件自动跟随深色/浅色模式：

```tsx
// 浅色模式
<svg className="text-green-400">...</svg>

// 深色模式（自动应用）
<svg className="dark:text-green-300">...</svg>
```
