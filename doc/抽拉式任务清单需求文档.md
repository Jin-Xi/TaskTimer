# 抽拉式任务清单功能需求文档

## 1. 功能概述

将当前右侧固定显示的任务清单改造为可折叠的抽拉式设计，提升空间利用率和用户体验。

```
│ 左侧导航 │   中间内容区    │  右侧任务清单         │
│ (300px) │    (flex-1)    │    (30%, 最小420px) │
└─────────────────────────────────────────────────┘
```

### 2.2 现有组件位置
- PC端右侧任务清单：`src/App.tsx` 第 433-438 行
- 移动端底部任务清单：`src/App.tsx` 第 422-430 行
- 共享组件函数：`SharedTaskList`（第 246-273 行）

## 3. 功能需求

### 3.1 PC端（宽屏，≥1024px）

**抽屉把手：**
- 位置：页面最右边框中间位置（垂直居中）
- 样式：竖向标签/图标，带有提示文字"任务清单"
- 交互：
  - 默认状态：任务清单隐藏，把手在边缘可见
  - 悬停时：显示展开预览效果
  - 点击后：任务清单从右向左滑出
  - 再次点击：任务清单向右滑入隐藏

**任务清单面板：**
- 滑出动画：平滑过渡，持续时间约 300ms
- 内容保持现有功能不变
- 宽度：约 30% 或固定 400px-500px
- 遮罩层（可选）：展开时添加半透明遮罩，点击遮罩关闭

### 3.2 移动端（窄屏，<1024px）

**抽屉把手：**
- 位置：屏幕下方中间位置（水平居中）
- 样式：横向标签/图标，带有提示文字
- 交互：点击后任务清单从下向上滑出

**任务清单面板：**
- 从底部向上滑出
- 高度：约 70-80vh
- 支持向下滑动关闭手势

## 4. 技术实现方案

### 4.1 状态管理
新增状态：
```typescript
const [isTaskDrawerOpen, setIsTaskDrawerOpen] = useState(false);
```

### 4.2 布局调整

**PC端布局（宽屏）：**
```tsx
{/* 抽屉把手 */}
<button
  className="fixed right-0 top-1/2 -translate-y-1/2 z-30 ..."
  onClick={() => setIsTaskDrawerOpen(!isTaskDrawerOpen)}
>
  任务清单
</button>

{/* 任务清单抽屉 */}
<aside
  className={`fixed right-0 top-0 h-full transition-transform duration-300 ${
    isTaskDrawerOpen ? 'translate-x-0' : 'translate-x-full'
  }`}
>
  <TaskList />
</aside>

{/* 遮罩层（可选） */}
<div
  className={`fixed inset-0 bg-black/20 z-20 transition-opacity ${
    isTaskDrawerOpen ? 'opacity-100' : 'opacity-0 pointer-events-none'
  }`}
  onClick={() => setIsTaskDrawerOpen(false)}
/>
```

**移动端布局（窄屏）：**
```tsx
{/* 抽屉把手 */}
<button
  className="fixed bottom-0 left-1/2 -translate-x-1/2 z-30 lg:hidden ..."
  onClick={() => setIsTaskDrawerOpen(!isTaskDrawerOpen)}
>
  任务清单
</button>

{/* 任务清单抽屉 */}
<aside
  className={`fixed bottom-0 left-0 right-0 transition-transform duration-300 lg:hidden ${
    isTaskDrawerOpen ? 'translate-y-0' : 'translate-y-full'
  }`}
>
  <TaskList />
</aside>
```

## 5. 样式规范

### 5.1 抽屉把手样式
- PC端：竖向排列，高度约 80px，宽度约 40px
- 移动端：横向排列，宽度约 100px，高度约 40px
- 圆角：朝向屏幕边缘的一侧为圆角
- 颜色：与主题色一致（indigo）
- 阴影：轻微阴影突出层次

### 5.2 动画效果
- 滑出/滑入：`transition-transform duration-300 ease-in-out`
- 遮罩层淡入/淡出：`transition-opacity duration-300`
