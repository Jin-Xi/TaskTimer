# AI 规划功能需求文档

## 1. 功能概述

AI 规划功能是 ChronoFlow 应用的核心功能之一，通过大语言模型（LLM）将用户输入的宏大目标自动分解为可执行的任务流水线。该功能基于工作分解结构（WBS）方法论，帮助用户将复杂目标拆解为层次化的任务列表。

## 2. 用户故事

### 2.1 主要用户故事
作为一个用户，我希望能够：
1. 输入一个宏大的目标（如"在一个月内开发一个 React 个人博客"）
2. 提供相关的背景信息和约束条件
3. 让 AI 自动生成结构化的项目计划，包括多个工作流和具体任务
4. 自动创建项目和任务到系统中，可直接开始计时

### 2.2 使用场景
- 学习计划：输入"在三个月内学习 Python 并完成一个数据分析项目"
- 工作项目：输入"开发一个移动端电商应用"
- 健康目标：输入"在两个月内减重 5 公斤"
- 创意项目：输入"写一本 10 万字的科幻小说"

## 3. 功能需求

### 3.1 输入界面
| 组件 | 描述 | 必填 |
|------|------|------|
| 核心目标输入框 | 用户输入主要目标，单行文本 | 是 |
| 背景信息输入框 | 用户补充背景、约束、偏好等，多行文本 | 否 |
| 生成计划按钮 | 触发 AI 生成项目计划 | - |

### 3.2 AI 处理流程
```
用户输入 → 调用 LLM → 结构化 JSON 输出 → 创建项目 + 任务 → 跳转到项目管理页
```

### 3.3 AI 输出格式
AI 必须返回以下 JSON 结构：

```json
{
  "projectName": "项目名称",
  "description": "项目描述",
  "color": "indigo|emerald|slate|rose|amber|cyan|violet|fuchsia",
  "tasks": [
    {
      "id": "t1",
      "title": "任务标题",
      "description": "任务描述",
      "estimatedMinutes": 30,
      "tag": "工作|学习|创意|运动",
      "parentIds": ["t0"]
    }
  ]
}
```

### 3.4 任务分解规则
AI 应遵循以下规则进行任务分解：

1. **层级结构**：遵循 WBS 原则，创建 3-5 个主要工作流
2. **任务粒度**：每个工作流下细分 3-5 个具体任务
3. **依赖关系**：通过 `parentIds` 定义任务前置依赖
4. **时间估算**：为每个任务预估合理时长（分钟）
5. **标签分类**：为每个任务指定合适的标签

### 3.5 界面状态

| 状态 | 描述 | 展示内容 |
|------|------|----------|
| 初始状态 | 等待用户输入 | 输入框 + 生成按钮 |
| 加载状态 | AI 正在处理 | 进度提示 + 动画 |
| 成功状态 | 计划生成完成 | 自动跳转到项目管理页 |
| 错误状态 | 生成失败 | 错误提示 + 重试选项 |

### 3.6 加载步骤提示
加载时显示以下步骤（每步约 1.5 秒）：
1. "正在拆解目标..."
2. "正在构建依赖关系..."
3. "估算任务耗时..."
4. "优化执行路径..."

## 5. 技术实现

### 5.1 技术栈
- **前端**: React 19 + TypeScript
- **AI 服务**: Google Gemini 3 Flash API
- **状态管理**: React Hooks (useState)
- **存储**: LocalStorage

### 5.2 API 调用
```typescript
// 服务: src/services/aiService.ts
generateProjectPlan(goal: string, context: string, config: AIConfig, language: Language)
```

### 5.3 数据流
```
AIProjectGenerator
    ↓ onPlanGenerated
App.handleAIPlanGenerated
    ↓ addProject, addTask
ProjectManager (显示新创建的项目)
```

## 6. 错误处理

| 错误场景 | 提示信息（简体中文） | 处理方式 |
|----------|---------------------|----------|
| API Key 未配置 | AI API key not configured | 显示配置提示 |
| 空目标输入 | 请输入目标 | 禁用生成按钮 |
| 网络错误 | 网络连接失败 | 显示重试提示 |
| AI 返回格式错误 | 无效的响应 | 显示错误信息 |
